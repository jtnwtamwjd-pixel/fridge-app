# 冷蔵庫ごはん：家族同期のための Firebase 設定手順

所要時間は10分ほどです。無料のプラン（Spark）のままで使えます。PCでの作業がおすすめです。

## 1. プロジェクトを作る
1. https://console.firebase.google.com/ を開いて Google アカウントでログイン
2. 「プロジェクトを作成」→ 名前は `fridge-app` など → Google アナリティクスは **オフ** でOK → 作成

## 2. ウェブアプリを登録して設定値をコピー
1. プロジェクトのトップで「</>」（ウェブ）アイコンを押す
2. アプリのニックネームに `fridge-app` と入れて「アプリを登録」（Hosting のチェックは不要）
3. 表示される `const firebaseConfig = { apiKey: "...", authDomain: "...", projectId: "...", ... };` の **{ } の中身をまるごとコピー**
   - この値はアプリに埋め込んで公開する前提のもので、パスワードではありません（守りは下のルールで行います）

## 3. 匿名ログインを有効にする
1. 左メニュー「構築」→「Authentication」→「始める」
2. 「Sign-in method」タブ →「匿名」→ 有効にして保存

## 4. Firestore（データベース）を作る
1. 左メニュー「構築」→「Firestore Database」→「データベースの作成」
2. ロケーションは `asia-northeast1 (Tokyo)` → 「本番環境モードで開始」→ 作成
3. 「ルール」タブを開き、中身を全部消して下をそのまま貼り付けて「公開」

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /homes/{home}/{col}/{doc} {
      allow read, write: if request.auth != null
        && home.size() >= 12
        && col in ['items', 'recipes', 'hist'];
    }
  }
}
```

## 5. 設定値を送る
手順2でコピーした firebaseConfig の中身を、スレッドに貼り付けて送ってください。アプリに組み込んで公開します。
（すぐ試したい場合は、アプリの「その他 → 家族と同期 → Firebaseの設定」に貼り付けても使えます。その場合は家族のスマホそれぞれで貼り付けが必要です。）

## しくみ（参考）
- 最初の1人が「家族のグループを作る」と、推測されにくい12文字の家族コードができます
- 「招待リンクを送る」で家族に送り、開いた人が参加すると、食材リスト・マイレシピ・作った記録が全員のスマホでリアルタイムに同じになります
- 家族コードを知っている人だけが読み書きできます。コードは家族以外に教えないでください
